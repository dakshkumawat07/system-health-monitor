# 🐧 System Health Monitor

A beginner-friendly Python-based Linux system monitoring tool that displays essential information about the system directly in the terminal. This project is being developed step-by-step to build practical Python, Linux, and software development skills.

---

## 📌 Description

**System Health Monitor** is a command-line Python project designed to provide useful information about a Linux system.

The project starts with basic system information and will gradually evolve into a more advanced monitoring application capable of displaying CPU, memory, disk, and overall system health information.

The project follows a version-based development approach, with new concepts and features introduced progressively.

---

## ✨ Features

### Current Features — v1.1

- 🖥️ Display operating system information
- 🔧 Display system release information
- 💻 Display machine architecture
- ⚙️ Display processor information
- 🧮 Display logical CPU count
- 🐍 Display Python version
- 🐧 Designed for Linux systems

### 1. Clone the Repository

```bash

```

### 2. Enter the Project Directory

```bash
cd system-health-monitor
```

### 3. Run the Program

```bash
python3 main.py
```
